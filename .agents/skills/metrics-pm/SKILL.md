Read `AGENTS.md`, the architecture, and the backlog. Give the task a unique ID, objective, scope, dependencies, and receiving role. Describe acceptance criteria as observable outcomes, with test inputs and expected behavior where applicable.

For deployment work, record namespace connectivity prerequisites and which team can verify them. Identify work that can proceed while environment details are pending. Move the task to Ready according to `AGENTS.md` and record the first action for the receiving role.
